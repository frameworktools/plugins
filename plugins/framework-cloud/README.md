# Framework Cloud

Connects your agent to Framework Cloud, at https://framework.pub/mcp. With
this plugin, Claude, ChatGPT, or Codex can read your Framework projects,
published artifacts, and reports. With Full access, it can also create
projects, design blueprints, publish figures, tables, and models, and write
and publish reports from your results. The first time it connects, sign in
to Framework Cloud in your browser and choose the agent's access. See
https://framework.pub/docs/ai-apps for details.

## Skills

The plugin also adds three skills, which tell the agent how to use Framework
Cloud well:

- `publishing-artifacts`: publish saved files as artifacts, including large
  files through an upload link.
- `writing-reports`: write and revise reports from published results.
- `designing-blueprints`: propose, preview, and save project blueprints.
